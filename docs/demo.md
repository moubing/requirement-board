# 游客体验

REQ-59 提供公开入口 `/demo`。登录页的「无需注册，体验示例文档」可以进入；已登录账号也可以直接访问。固定展示「编辑器功能导览」，不接受文档 ID、版本 ID、图片 ID 或其他 URL 参数来选择业务数据。

## 可以体验什么

正文使用现有 `RichRequirementEditor`，支持文字、格式、代码、表格、任务清单、目录和普通撤销/重做。`RichTextDiffViewer` 在本机真实计算预置 v1/v2/v3 与当前临时内容的差异；只有目标为临时内容时提供局部恢复，恢复进入普通撤销历史。

导览使用真实节点逐项展示 H1–H3、普通段落与换行、行内格式和链接、无序/有序列表、任务、引用、四种提示块、代码、表格、图片及题注、折叠块和分隔线，并说明各自的操作方式。最后一节介绍并排/统一、仅变化、版本选择及局部恢复。v1 是基础示例，v2 演示文字与格式变化，v3 增加段落和表格行、删除旧段落，并更新任务与代码，所有差异均由真实 Diff 计算。

三个示例版本的正文开头均用说明块明示：游客体验只展示部分基本编辑与版本比较功能，并非完整功能演示；多人协作、正式版本保存、图片上传、AI 标注、选区历史等功能未在本页开放，需进入正式应用使用。

修改只存在于当前页面实例。刷新、离开再进入、浏览器恢复页面快照或「重置示例」恢复 v3；重置同时清空撤销和比较状态。两个标签页及不同浏览器上下文互不影响。顶部持续说明临时状态，保存按钮禁用，Ctrl/⌘ S 只解释限制。

桌面顶部使用两行紧凑工具栏：标题、游客限制和源码链接在第一行，正文/比较切换、修改状态及重置/保存操作在第二行。窄屏按组换行；操作说明保留在示例正文中，版本说明在版本选项详情中查看，避免顶部重复占位。

示例包含稳定且唯一的 diffId；所有版本、虚构作者、代码、题注均维护于 `shared/demo/document.ts`，唯一图片是随代码发布的 `public/demo/nodes.svg`。链接节点仅示范用户提供的公开 GitHub 主页。增加示例资源必须同时审核全部版本及白名单，不能引用 `/uploads` 私有文件或外部图片。

## 数据边界

- 认证路由中间件仅对精确 `/demo`（可带末尾斜线）跳过账号读取；不改变账号状态，也不修改 `requireAccountContext`、`requireAppContext`、业务 API、私有图片和协作入口的授权。
- `DemoHeader` 替代业务 Header，不挂载搜索、最近浏览、新建、账号或成员入口。切换仍保留已有真实详情页的缓存边界与离页保护；游客页面自身不参加 KeepAlive。
- 示例页面不传 `requirementId`、协作对象、草稿备份、AI 标注或上传检查点，不接入 Yjs/Hocuspocus、IndexedDB、版本正文缓存、个人草稿或 Agent。没有文档身份的编辑器不注册业务阅读位置状态。
- 编辑器新增可选的 `allowImageUpload`（默认 true）、`allowedImageSources`（默认不限制）和 `allowSelectionHistory`（默认 true）。游客页关闭上传与历史入口；工具栏、斜杠菜单、文件选择、粘贴/拖入文件和上传队列均受限制。HTML 在解析前移除未批准资源，Markdown、拖放和直接节点事务由图片白名单守卫阻止，未批准图片不会进入 NodeView 或 Diff。预置图片可以复制、缩放、对齐、改题注或删除，这些操作仍只影响页面副本。
- 主题沿用全局外观偏好 Cookie；它不保存示例内容，不授予业务权限。游客页不展示模拟在线成员、AI 执行或同步成功。

本功能没有数据库迁移，不创建游客账号、项目成员、公开协作房间或服务端演示记录。

## 源码入口

`NUXT_PUBLIC_DEMO_SOURCE_URL` 配置「查看项目源码」的 HTTPS 地址，默认是用户指定的 `https://github.com/moubing/requirement-board`。非法地址回退到该默认地址。

## 验证

`tests/diff/demo-document.test.ts` 使用真实 schema 与 Diff 检查全部样例、块身份、资源和副本隔离；`image-source-policy.test.ts` 检查 HTML/Markdown/节点命令的资源限制及普通编辑器兼容；`tests/auth/demo-route.test.ts` 检查精确路由与身份边界。

在本机隔离库运行 `$env:BROWSER_TEST_SCENARIO='demo'; pnpm test:browser`（PowerShell）。该场景编译临时 Nuxt 应用，使用真实 SSR、路由、认证、业务 API、WebSocket 和 PostgreSQL；编辑器操作不替换接口响应。它检查编辑/撤销/比较/局部恢复/重置、多标签隔离、刷新与离页、请求与浏览器存储隔离、所有数据库表的前后摘要、匿名 HTTP/WS 拒绝及登录账号草稿保留，并覆盖 320/390/960/1440px 亮暗界面、键盘和减少动态效果。可用 `BROWSER_TEST_DATABASE_URL` 指向本机名称以 `_browser_test` 结尾的专用库。

`BROWSER_TEST_ARTIFACT_DIR` 可输出截图，视觉核验后清理。浏览器始终无头；这不代替所有真实设备和系统输入法验证，也不表示已部署到线上。
