# 公开发布说明

本仓库于 2026-11-14 从当前源码建立独立的公开提交历史。公开范围为源码、测试、锁文件、通用配置、开发文档与经检查的展示素材。内部完整开发历史继续由内部仓库维护，公开仓库只推送经过检查的 main，不镜像内部的分支、标签或远程配置。

## 排除与脱敏

- 不发布真实环境文件、Token、密码、私钥、凭证配置和认证浏览器状态。
- 不发布数据库备份、用户上传文件、私有文档导出、运行日志与性能 Trace。
- 不发布本机仓库映射、IDE 缓存、依赖目录和构建产物。
- 内部 CI/CD、服务器配置、证书续期与备份资料已排除或改为通用说明；保留运行必要的迁移和安全示例。
- 内部 Git 链接改为 GitHub，私有需求链接改为文字；机器路径使用通用示例。
- 页面中有意对外展示的站点导航可保留；它不包含内部管理入口或认证信息。

## 发布后的维护

GitHub 与内部仓库具有独立历史。后续更新从受控源码导出、复核差异并脱敏，在已有 GitHub main 上创建正常提交。不要把内部 origin 的完整历史合并或强推到这里，也不要使用 push --mirror 或自动推送全部标签。

更新前检查 Git 已跟踪内容与实际待推送的历史；忽略规则不会移除已进入历史的文件。密钥扫描只是辅助证据，需要结合配置、示例、素材和第三方文件的人工检查。

## 许可与第三方文件

本次发布没有替作者新增主项目许可证。第三方字体、图标等保留各自随仓库提供的许可文件；这些许可只覆盖对应资源。新增或替换第三方资源时核对来源与分发条件。
