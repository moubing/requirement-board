# 编辑器、正文模型与版本 Diff

涉及节点、粘贴、图片、表格或版本比较时，须同时检查编辑器、服务端校验和只读渲染。共同持久化见 [collaboration.md](collaboration.md)，本机恢复和切页保护见 [drafts.md](drafts.md)。

## 模型与校验

| 层 | 入口 |
| --- | --- |
| JSON 类型、规范化、块 ID、纯文本 | `shared/editor/document.ts` |
| Tiptap 运行时扩展 | `app/components/editor/tiptap-extensions.ts`、`RichRequirementEditor.vue` |
| 服务端 schema | `shared/editor/validation.ts` |
| Diff、选区历史、草稿撤销 | `shared/diff/` |
| 只读展示 | `app/components/diff/` |

正式正文为 `{ type: 'doc', content: RichTextNode[] }`，HTML 只用于展示或剪贴板。`contentText` 由服务端 `extractPlainText` 派生：递归提取文本，图片优先题注、其次 alt，节点间换行并压缩过多空行。

### 稳定块 ID

`BLOCK_NODE_TYPES` 包括 paragraph、heading、blockquote、codeBlock、horizontalRule、bulletList、orderedList、listItem、taskList、taskItem、details、detailsSummary、image、callout、table、tableCell、tableHeader。tableRow 和 detailsContent 是结构节点，不拥有 ID。单元格内文字编辑和目标外行列变化保留身份，合并、拆分、类型/跨度改变时为受影响单元格分配新身份；其余单元格保持不变。ID 修复与原事务共享撤销边界，历史 Diff 忽略纯 ID 变化。

- `BlockId` 为缺失或重复 ID 分配新值，保留已有稳定 ID；修复事务继承原操作的 `addToHistory`，不能让新增、拆分或格式操作失去撤销步骤。
- 远端事务保留发送端 ID，但其后本地插件追加的节点仍须补 ID，例如主动编辑后的 TrailingNode 空段落。
- 恢复旧本机备份时，可编辑实例沿原 Yjs 文档修复缺失/重复 ID，不进入撤销栈；只读实例不修复。
- 粘贴先移除切片中的 ID，再为副本分配新值，不让插在前面的副本抢占原节点身份。
- `ensureBlockIds` 原地修改对象；须保留输入时先 `cloneRichTextDocument`。它还把图片未知 align 归为 center，并补旧 imageCaption。

无故重建 ID 会破坏块对齐、选区追溯和草稿撤销。模板创建或复制另需重分配全部 ID，普通模板编辑保留原 ID，详见 [模板契约](document-types-and-templates.md)。

### AI 标注与正文隔离

在正文视图按 `Ctrl+Alt+2` 可复制当前文档的全部 AI 标注，并展开 AI 标注面板查看结果，等同于点击「复制给 AI」。按钮文字始终保持「复制给 AI」；两种入口复制成功后均使用 BingToast 的 `top-center` 位置，在视口顶部居中提示「AI 标注已复制」。快捷键复用同步、定位和剪贴板失败提示；没有标注、正在复制、按住重复触发或填写标注/其他模态弹窗时不执行复制。它在编辑器前拦截，不触发二级标题格式，也不修改正文。

`RequirementAnnotationOverlay` 在 ProseMirror 外通过 DOM Range 绘制绝对定位高亮。单行编号优先悬浮在选区末端上方，空间不足时避让到末端旁的空白或页边；折行和跨段选区按整体范围定位，编号放在左侧页边的顶部位置，输入框靠左放在整体上方。窄屏编号限制在正文视口内并避让文字。同一行的加粗、链接等多个矩形不视为多行。不得把编号放进文字行内、增加正文 mark/node 或用占位扩大行高；滚动、字号、宽度和文档布局动画时重算几何位置。浮动输入框复用 BingCard、BingTextarea、BingButton，取消和保存图标与输入区横排，编号和高亮跟随项目主题。支持 Enter 保存、Shift+Enter 换行和 Escape 取消，中文输入法确认候选不会提交。输入框限制在正文视口内，不为添加标注改变正文宽度；正文选区和普通复制仍只包含原文字。

点击标注列表、编号或编辑入口时，先隐藏文本快捷菜单，通过 ScrollToPlugin 只平滑滚动正文内部 viewport，多行选区定位到起始行，并在上方留出填写要求的位置；到达后短暂强调对应原文，编号通过独立容器以下方支点做逐次减弱的圆弧摆动，不增加描边或覆盖 BingButton 自身动效。跨屏拖选后添加标注也会带回选区起点。重复点击会重新提示，连续选择取消上一轮定位。尚未进入填写状态时，用户滚轮、拖动或滚动按键中止定位；原文变化、删除目标、隐藏编辑器和卸载时清理动画及变换。减少动态效果时直接定位并保留一次静态强调。窄屏先收起辅助抽屉再定位，编号和输入框继续锚定原文。

`RequirementAnnotationComposer` 复用 BingDialog 的模态层、焦点恢复和滚动锁，面板仍按业务选区定位、背景保持透明。填写期间在窗口捕获阶段拦截外部点击、页面滚动和快捷键，输入框绕中心轻晃并保持输入焦点；Tab 在三个表单控件间循环。BingTextarea 自 0.10.0 默认提供平滑光标，包含跨行位移；输入值即时更新，原生文字编辑、输入法和输入区自身滚动不受影响。连续干扰只播放一轮反馈，减少动态效果使用静态提示及原生光标；尺寸测量采用不含旋转的高度，避免晃动改变锚点。临时失去原文矩形时保留最近位置，确保取消入口可用；保存、取消、隐藏编辑器和卸载均清理监听、滚动锁与动画。

面板内的滚动事件交给 BingTextarea 与 BingDialog 处理：输入区到达首尾、内容不足以滚动或操作滚动条时都不触发晃动，边界滚轮由 Dialog 阻止传到背景。只有面板外的滚动尝试才触发输入锁反馈。

`annotation-edit-guard` 在本机正文事务写入前检查标注定位；输入、删除、粘贴或拆段将使有效标注失效时，用 BingDialog 提示确认。确认仅清除受影响的本机标注，再应用一次原输入；取消保留正文、选区、撤销栈及协作数据，多条标注合并确认。输入法在开始组词时先确认，取消不写入拼音，确认后重新开始正常组词，不重放未确定的候选文字。无关编辑和不影响定位的格式修改直接通过。原文加载、远端同步与协作撤销不在视图层阻断；等待确认期间若正文被这些操作改变，取消待处理输入并提示重试，禁止重放过期事务。既有失效标注仍提示重新标注；正文撤销不恢复已确认清除的本机标注。

文字标注按注册为文字块的节点（段落、标题、代码块、提示块）diffId 保存 Unicode 码点范围，另带 topLevelId，跨段保留逐段范围。提示块、图片、整表、单格统一注册为 node 整体目标；表内图片同时提供图片、所在单元格、整表三项。鼠标从本次命中的 PM 节点及可标注祖先生成菜单，键盘 ContextMenu/Shift+F10 使用节点选择、控件焦点或节点内折叠光标；多格/混合选区提示重新聚焦。触屏接管图片画面或节点留白的 500ms 长按，移动超过 8 CSS px、滚动和第二指取消；文字长按保留原生行为。打开菜单时冻结目标，点选后再次核验。普通新节点只在共享注册表声明能力，接入规则见 [节点标注能力](annotation-nodes.md)。

对象边框与编号仍为正文外浮层，不改变正文、布局或 undo；内部表格滚动裁剪边框，定位先水平揭示再纵向滚动。列表显示图片缩略图或单格逻辑行列及跨度。对象签名严格包含文本、marks、链接、图片资源/说明、结构与跨度，排除 diffId、图片显示尺寸/对齐及 colwidth。共享解析器不会把失效对象转移到相似图片或格子。表内文字子范围、题注选区、跨格及混合选择不支持，使用对象菜单。存储、复制及 Skill 契约见 [AI 标注](agent-editing.md#从网页传递-ai-标注)。

### Schema 边界

服务端依次验证 Zod 外形、未知 node/mark/attrs、项目属性，再用 ProseMirror `nodeFromJSON(...).check()` 检查嵌套结构：

- heading 仅 level 1–3；callout 带 tone 与稳定 diffId。
- image 的 src 非空且拒绝 data:；width/height 存在时须为正数，align 为 left/center/right，并包含 imageCaption。
- 解析 HTML 的裸 img 与自定义 figure 都检查地址；无效图片不生成节点，题注文本仍保留。
- link 支持网页、邮箱、电话及相对地址，拒绝 javascript/data/vbscript/file 等协议。
- 表格行、表头、单元格按 TableKit schema 校验。

保存 API **先校验，再补 ID**；加载旧数据的规范化不能被当作服务端接受非法 JSON 的理由。新增 node/mark 必须同步运行时和服务端 schema。

## 数据更新与撤销历史

`RichRequirementEditor` 输入/输出 RichTextDocument；外部更新替换整个 modelValue 对象，不原地改嵌套字段。自身发出的对象回传时跳过重复导出，目录和图片预览复用最近快照；选区、光标和 Awareness 不触发全文派生。

固定游客样例通过可选的上传、图片来源和历史入口限制复用编辑器。默认业务行为不变；限制同时覆盖入口与正文事务，而不只隐藏按钮。无文档身份时不注册业务阅读位置；游客局部恢复复用 `restoreVersionChange` 的普通撤销事务。具体数据边界见 [游客体验](demo.md#数据边界)。

网页保留 StarterKit 的 `TrailingNode` 默认体验：以图片、表格、代码块、列表等非 paragraph 节点结尾时保留一个空 paragraph；已有普通段落（包括有文字的段落）不再追加。`shared/editor/trailing-paragraph.ts` 在 AI 候选、文档/模板创建和版本保存前应用同一规则，保留已有节点、ID 和额外空段。普通编辑器在装载前规范化；共同文档新建和后续写入也沿 Yjs 历史补齐，并同事务保存二进制和 JSON，使新写入的正文与正式版本一致。

不迁移旧数据或改写历史快照，也不在修改状态和 Diff 中忽略尾段。旧版本缺少尾段、当前正文已经自动补段的文档仍显示有改动；再次正式保存后，以包含尾段的新版本作为基准。额外空段、普通文字段落后的空段和实际输入照常参与比较。图片题注 Enter 继续复用后续段落；表格、代码块后可直接点击空段输入。

只读/可编辑状态切换使用 `setEditable(value, false)`，不触发 Tiptap 默认的正文 update，也不导出或回传整篇 JSON；真实输入、远端正文变更和撤销/重做仍按原流程更新快照。

编辑器的 `active` 默认开启。隐藏正文或缓存页停用时，暂停视口、目录、阅读锚点、标注几何测量和全局交互监听；正文、NodeView 和协作历史继续保留。阅读位置在可见时捕获，恢复只在当前激活代次执行，用户已经滚动或点击后不再覆盖其位置。

图片保留稳定的图片、题注和缩放容器，仅在悬浮、选中、键盘焦点或正在操作时创建工具条及缩放手柄。宽度 ResizeObserver 也随交互启停；键盘可从预览按钮进入操作区。图片退出动画、对齐动画和上传入场在页面隐藏时结束，避免后台测量或抢焦点。

详情页的比较器首次打开时创建，随后显隐复用。`active=false` 时不计算新 Diff、不测量布局，恢复后只处理最新正文。结果按账号、文档、editEpoch 隔离，以版本对及不可变正文对象身份复用，每个比较器最多保留两组结果和对应折叠/导航/滚动状态；不为显隐切换序列化全文。历史正文缓存最多六份，重复读取同一不可变版本保留对象身份，停用取消未完成请求，迟到响应不得回填已取消缓存。

协作模式使用 Yjs 的个人撤销，不撤销他人的输入。结构变化与 ID 修复合为同一步；相关依赖补丁及升级回归见 [共同编辑](collaboration.md#接入方式)。

同一文档切换正文/比较时用 v-show 保留编辑器、连接和上传任务。跨页面先完成备份，详情实例进入最多两篇的 KeepAlive 缓存；命中时复用原编辑器，淘汰后正常销毁并按检查点恢复内容和阅读位置。不新增跨页面持久撤销栈承诺，修改属性也不能重新初始化正文。

个人字体、字号、颜色、行高和宽度作用于正文、只读内容、Diff 及预览，不写 JSON/Yjs/历史，不覆盖链接、高亮和 Diff 状态色。正文字体另覆盖文档标题和选区历史正文，代码字体独立覆盖行内/块级代码及其 Diff；标题字号、界面控件、AI 标注浮层不随之改变。持久化规则见 [全局界面与主题](architecture.md#全局界面与主题)。

## 输入与剪贴板

### 正文斜杠命令（REQ-34）

段落、标题或提示块的开头，以及前一个字符为空白时，输入 `/` 或 `／` 打开本机命令菜单；`、` 只在文字块开头触发。普通粘贴、装载正文和远端更新不打开菜单。中文组词期间保留已打开菜单的候选、选中项和位置，提交后才更新筛选；方向键、Enter/Tab/Escape 仍交给输入法，候选选区变化不关闭菜单，也不执行命令。未打开的菜单只在触发符提交后出现。代码块、图片题注、只读、AI 锁定及停用的正文不触发。菜单按中文名称与英文别名筛选，方向键循环选择，Enter/Tab 确认，Escape、外部点击、删除触发字符、移动光标、正文滚动及远端更新关闭。取消保留输入，无匹配时 Enter/Tab 不改正文。

每个命令只保留一个英文别名，菜单右侧显示该别名：正文 `text`，一至三级标题 `h1`/`h2`/`h3`，无序/有序列表 `ul`/`ol`，引用 `quote`，四种提示块 `note`/`tip`/`warning`/`danger`，代码块 `code`，分隔线 `hr`，表格 `table`，图片 `image`。筛选对中文名称和这个唯一别名做不区分英文大小写的包含匹配，不再匹配已移除的其他别名；右侧不显示快捷键提示。

命令复用现有节点和 Tiptap 操作，按当前位置实际探测可用性，单元格内不提供嵌套表格。四种提示语气分别列出，表格默认为带表头的 3×3。任务清单可用中文或 `task` 搜索；折叠块可用中文或 `details` 搜索。

触发、筛选、删除命令及插入合并为一次普通/Yjs 撤销，停顿筛选仍保持此边界，前后普通输入独立；选择正文且没有格式变化时结果本身已回到触发前，不制造空撤销事件。图片选择期间保持命令菜单关闭，取消或文件无效时保留命令文字；有效文件走原上传队列，不再输入或移动光标时，异步插入仍合入本次撤销。等待中继续编辑、远端修改、失败/取消则结束该合并窗口，图片重试沿用原流程。小图加载后尺寸相同时不追加无效属性事务。

菜单状态、方向键选中项和定位不写正文、Yjs 或 Awareness。BingDropDown 0.15.0 的 `anchor`/`boundary` API 使用光标矩形和真实正文 viewport，负责上下翻转、宽高约束及内部滚动；应用不接触组件内部定位 DOM。隐藏正文会关闭菜单并释放监听，不重建编辑器。组件库源码、正式发布依赖与文档同步；后续发布前联调可通过 `BROWSER_TEST_UI_CANDIDATE=1` 验证。

### 通用输入与剪贴板行为

| 场景 | 约束 |
| --- | --- |
| 停止格式继承 | `Ctrl/Cmd+Alt+\` 清空输入 marks；优先读取 storedMarks，空数组表示明确退出。仅折叠文本光标可用，选区、只读和 IME 期间不执行；不产生正文更新或撤销步骤 |
| 复制/剪切 | 同时提供 HTML（含 data-pm-slice）与纯文本；仅文字块间分行，保留空段、hardBreak、代码空白和选中单元格范围 |
| 异步剪切 | 剪贴板授权后再次核对正文与选区，防止删除已变化的范围 |
| 粘贴 | HTML 优先；无 HTML、非 Ctrl+Shift+V 且不在代码块时检测 Markdown。按开放切片替换选区，不制造首尾空段 |
| Mark 粘贴规则 | 默认关闭，防止二次解释富文本中的字面 Markdown；输入规则和自动链接保留 |
| Windows 内部 HTML | 带 data-pm-slice 时先提取 StartFragment/EndFragment，避免包装 CRLF 成为 hardBreak；外部 HTML 保留祖先格式，不能全局 trim |
| 连续有序列表 | 只合并粘贴触及的同级、同编号样式的相邻列表，沿用首段起号；保留旧 ID，合并与粘贴共用撤销步骤，远端/历史重放不再归并 |
| 空段落 | 编辑和只读状态均常驻显示“¶ 空段落”，仅为视图标记；不写正文、纯文本或 Diff token，不与对侧缺失块的空白混同 |
| 剪贴板图片 | 优先 items，再回退 files，走正常上传流程 |

文本快捷菜单在拖选期间隐藏，主指针释放且最终布局稳定后显示；连续多击、键盘扩选和触摸选区采用尾随延迟，避免对中间选区反复动画。入场仅渐显，不使用 scale/translate 扩张按钮边缘。

## 滚动、目录与光标

编辑器使用独立 BingScrollbar，工具栏在滚动区外。按真实顶部、可视高度及底部留白计算高度，上方提示或工具栏变化时重测，不写死页面 vh 偏移。嵌入卡片时可用 `viewportBottomGap` 预留卡片和页面底部间距；默认仍为12px，模板桌面编辑使用48px。滚轮到边界时阻止链传页面；ProseMirror scrollThreshold/scrollMargin 与 scroll-padding-block 保持相同安全距离。

点击相邻可编辑文本块短间隙时保留原光标/选区，不插入空段；不能覆盖正文点击、拖选、修饰键、双击选词或表格/图片的结构交互。

分隔线、图片等非文字块之间保留 Tiptap GapCursor 的插入能力：点击只定位，输入时才创建普通段落。块间光标使用跟随主题色的 2px 细竖线，避免默认黑色短横线看起来像多余的下划线；减少动态效果时保持常亮。这里只调整显示样式，不提前插入空节点，也不改变正文或协作数据。

平滑文字光标的边界：

- 右键坐标命中单元格等容器的留白时，先解析为最近的有效选区；容器末尾向内查找，避免落到下一格。不能直接在块边界创建文字光标，否则零高度坐标会显示为小圆点。单元格的鼠标右键在 mousedown 捕获阶段统一定位并阻止原生二次定位，菜单打开时相同选区不重复提交，避免光标先靠近字符再跳到段首。左键、图片/链接、只读与正在组词时保留原事件路径；键盘和触屏继续由菜单入口定位。菜单定位不修改正文或撤销历史。
- 空文本块（含空列表项）用 Decoration.widget 在真实选区提供零宽锚点，不用可能偏向邻块的 coordsAtPos(..., 1)；输入首字后移除锚点。
- 上传占位携带独立的零宽文字行锚点，同位置的光标只测量这个锚点，不取预览块的坐标或高度；行首和空段也由上传锚点定位，并在整个上传期间保留它，避免输入首字时移除定位 DOM 打断中文组词。等待、失败、重试和取消不改变真实输入选区；占位仍按原事务/Yjs 位置映射，上传成功沿用原插入语义。
- IME 组词时读取浏览器 DOM 焦点端，不能修改真实选区、焦点或组词节点；输入/选区通知每帧合并测量，位置不变不重复写样式。
- 图片缩放期间光标直接跟随文本布局并保持常亮，不叠加自身的位移过渡或反复启动闪烁；结束后恢复正常平滑移动与闪烁。缩放状态通过编辑器 DOM 事件传递，取消、失焦、移出窗口、页面隐藏和卸载都须结束状态，不修改真实选区。
- 测量失败、触屏或减少动态效果时回到原生光标。所有锚点和显示状态不进入正文、Yjs 或撤销历史。

目录从 JSON 提取带 diffId 的 H1–H3，按内部 viewport 同时激活可见标题；没有标题可见时取上方最近一项。轨道用 transform 覆盖首尾激活项，点击通过 ScrollToPlugin 只滚内部视口，尊重减少动态效果。

目录被 hideOutline、非活动编辑器或比较模式隐藏时，停止标题扫描、滚动/布局监听与测量帧，取消滚动动画；显示后重新计算。详情页通过 externalOutline/outlineActive 将目录交给右侧辅助面板，只有目录 Tab 可见时启用；窄屏抽屉中的目录仍可使用，点击即时定位后收起抽屉。独立编辑器的内置目录继续在 ≤1240px 隐藏。不能只靠 CSS 隐藏保留后台测量。

代码和表格的 NodeView 用 BingScrollbar 横向滚动，表格继承 TableView 保留 colgroup、单元格选区和命令。包装不序列化，内容仍由 ProseMirror 管理；卸载销毁滚动组件。固定预留 12px 底部轨道空间，并由独立 Vue 组件拥有 ref，不能在 NodeView 命令中直接渲染无所属实例的 ref VNode。

### 表格列宽

`ResizableTable` 复用 TableKit 的列边线命中和装饰，插件及普通 NodeView 都使用 `ScrollbarTableView`。列边线左右 4px 可命中，2px 强调线使用 `--ui-accent`，通过公开的 `data-bing-cursor="col-resize"` 协调全局指针。只读、AI 锁定、非活动编辑器和粗指针设备不显示手柄；锁定解除后可直接恢复调整。

拖动只改 colgroup 预览，最小列宽 80px；松手后按最新文档一次更新该列所有单元格的原生 `colwidth`，独立于前后输入撤销。双击清除该列宽度，恢复自动分配；Escape、窗口失焦、页面隐藏和卸载取消预览。沿用图片缩放的布局/状态事件，让平滑光标跟随换行且常亮。恢复自动宽时要移除 col 上残留的固定 width，不能仅设置 min-width。

拖动开始记录表格和列内单元格的稳定身份、合并格内偏移。远端插列/删行/编辑文字后按幸存身份重新定位；目标删除或身份对应多个列时取消，不能靠旧的数字列索引写邻列。跨行单元格只写一次，其他列宽、身份、正文与远端修改保持不变。不增加正文属性或 schema 版本；现有草稿、Yjs、正式版本及修改状态流程直接保存这一属性变化。

只读版本沿用相同 colgroup。Diff 按两侧列宽共用一个缩放系数，最大参考宽度 720px，同时保证最窄列不小于 80px；因此过宽表格在差异块内横滚。自动列以 80px 为比较基准，双方全自动时仍填满容器。仅列宽变化显示“列宽调整”和既定修改色，文本不产生字符增删。完整比较、版本标记卡片和选区历史共用 `DiffBlockRenderer`；本需求不扩大选区历史原有的文字追溯范围。设置预览也使用相同表格样式和横向滚动。

## 图片交互

上传任务及 Blob 的持久化见 [草稿图片流程](drafts.md#图片与清理)。编辑器负责：

1. 上传期间在原位置放 Decoration 预览，按事务及 Yjs 相对位置恢复；占位不进入 JSON、Diff 或 revision。连续粘贴的每张图片都是独立任务；插图拆段或替换空段时不能让事务映射丢掉其他任务的占位，只有完成、取消或清空任务才移除占位。
2. 预览按天然比例确定尺寸；成功后先解码正式 URL，再等尺寸插入带稳定 ID 的图片。确认正文实际包含该图片后才结束任务，插入被拒绝时保留失败占位和已上传资源供重试。已有同任务图片不能重复插入。同位置的任务按粘贴顺序定位在新图片前后，失败重试不改变顺序；完成后更新剩余占位的 Yjs 相对位置，避免远端更新把它们移回旧段落。
3. 插入后仅在图片未完整可见时滚动内部 viewport，保留底部间距；用户输入可中止，减少动态效果时直接定位。
4. 未完成或失败未处理的占位阻止保存版本和进入 Diff；支持重试/移除，卸载或移除时中止请求并释放 object URL。AI 只读期间不得由异步回调插入正文。

图片工具栏以整行作 hover 区域，focus-within 保留键盘操作。左/中/右对齐同步移动图片、题注和工具栏；动画每帧及清理时通知光标重测。删除先退场再删节点，后续可见块用有数量上限的 FLIP 回流；仅动画 opacity/transform，减少动态效果或卸载时直接完成并清理。

图片预览按钮的 mousedown 继续传给 NodeView，保证内部拖动用原节点切片，保留地址、题注和 ID；阻止传播会退回 DOM 导入并污染正文。

“复制图片”按天然尺寸生成 PNG，保留透明度，动图取静态帧，不包含题注或控件。ClipboardItem 接收 Promise，并在点击时立即调用 clipboard.write，避免丢用户激活；加载、权限或跨域失败明确提示，不退回复制地址。操作不改变选区、正文或历史，复制期间禁止重复请求。

题注的点击落光标和鼠标拖选由浏览器与 ProseMirror 原生处理；不在题注 `mousedown` 中阻止默认行为或强制折叠选区。图片 `img` 的原生拖动限制及图片节点自身的移动处理不能扩展到题注文本。题注应支持双向拖选、局部复制/替换/删除及撤销，并能在编辑其他正文或粘贴图片后重新进入。

题注键盘规则：

- Enter 进入图片后紧邻段落；没有段落则插入带 ID 的空段，已有则复用，不在题注换行。
- 最后一行 ArrowDown 进入下一图片题注开头，第一行 ArrowUp 进入上一题注末尾，不创建节点。
- 键盘扩展优先于 GapCursor，并用选区事务兜底区分上下方向；题注外 Enter 保持默认行为。

结构性 FLIP 只处理拆分/合并、顶层增删、列表项和表格结构变化；普通字符、marks、选区、外部 setContent 和等尺寸上传替换不触发。旧布局捕获视口内及即将进入的有限顶层块，包括可能因滚动锚定移动的前方块；按 diffId 对齐新布局。用编辑区外临时样式驱动 transform，每帧通知光标，连续事务先清理上轮动画。

动画仅匹配前后文档中各自唯一的块 ID。遇到恢复过程中的重复 ID 时跳过该块，避免将首屏段落匹配到文末副本并移出视口；正文与协作历史的恢复仍由共同编辑流程处理。

## 详情工作区与版本选择

当前仅正文、版本比较两种视图，共用顶部操作栏。桌面状态/负责人/优先级位于视图切换右侧，与共同编辑、同步、保存及更多操作保持同一行；格式栏紧接操作栏，不另设属性行。右侧辅助面板默认目录，另有文档信息/AI 标注；BingSplitPane 提供360px偏好和320–560px调整，窄屏使用 BingDialog 抽屉与确认后提交的属性弹窗。格式栏在正文滚动区外，段落样式菜单沿用 Tiptap 正文/H1/H2/H3 命令。正文默认最大宽880px；比较时隐藏辅助面板。完整尺寸与断点见 [UI 规则](ui-rules.md)。

正文首次恢复与缓存页返回核对沿用项目动态的加载节奏：连续等待超过 150ms 才在内容区域显示文档骨架屏，淡入淡出各 100ms，不占布局空间。编辑工具栏从页面首次显示起保留，就绪前显示禁用按钮，和真实编辑器共用格式工具的定义及分组；缓存返回沿用已有工具栏。骨架及初次失败提示只覆盖工具栏以下区域，按工具栏实际高度适配窄屏换行；不提前创建非协作编辑器，也不把旧文档的命令交给新文档。骨架按文档标题、版本信息与正文段落排布，宽度跟随正文偏好和窄屏留白，使用主题中性色及轻微明暗变化；已有编辑器和阅读位置在其下保留，等待期间内容不可交互，顶部导航和辅助面板仍可使用。恢复结束立即交还操作，不强制停留；切换视图、停用或卸载取消显示计时，减少动效时骨架静止并直接显隐。加载状态独立于只读状态，失败结束骨架展示：首次恢复失败在正文区显示原因与重试，缓存页详情核对失败保留重新读取入口，协作恢复失败沿用草稿同步提示与重试。

`reading-anchor.ts` 在正文 viewport 宽度变化时恢复首个可见段落 diffId 与相对偏移；保留编辑器、ProseMirror 选区和撤销栈，仅调整内部 scrollTop。候选块结构变化时失效，普通输入从上次可见邻域测量；零宽度不覆盖最后有效位置。阅读位置恢复写入后派发 `EDITOR_READING_POSITION_RESTORED_EVENT`：锚点按代次作废恢复前已测量的锚点和宽度还原，先以恢复后的像素位置为准，宽度未变的下一帧再细化为段落；返回缓存页时若侧栏等布局在细化前改变正文宽度，保持恢复位置而不退回旧锚点。目录缓存标题及其内容坐标，滚动复用坐标；结构、尺寸、图片动效和标题变化失效，普通输入空闲后补核。正文阅读位置、锚点、目录和平滑光标共用帧内先测量后写入的调度，隐藏取消工作；关闭面板、导航变化和设置宽度共用这些约束。

正文和比较分别保留独立的布局层；比较首次打开后保留 DOM，非活动层用 visibility、inert 与 aria-hidden 隐藏并暂停视觉工作。正文层的侧栏宽度不随视图切换改变，比较保持全宽，避免热切换整篇重新折行。比较的零宽度容器不改写最后稳定的并排/统一布局；快速反向切换以最新恢复代次为准。

用户选择正文/比较时，标签选中态即时更新，实际内容切换经 `afterNextPaint` 给点击反馈一次绘制机会；不等待整个动画。快速反向选择、页面停用或卸载取消尚未执行的切换，提交时复核页面活动、保存与未完成上传状态。章节定位等程序化切换直接设置视图并取消旧任务，编辑器、正文和撤销栈继续保留。

字体切换复用阅读锚点恢复：只监听 HTML 上正文/代码字体变量的实际变化，字体加载完成时补测，不因配色更新恢复滚动。换行期间不覆盖旧锚点；恢复后派发 `EDITOR_LAYOUT_MOTION_FRAME_EVENT`，使目录、AI 标注、版本标记和平滑光标更新，即使总高度没有变化也能刷新行内坐标。停用时移除字体监听，不重建编辑器或撤销栈。

离开详情后，未选中的层额外退出布局，返回时只排版当前视图；再次显式打开该层后恢复本次激活内的尺寸保留。这样不会在每次返回正文时顺带排版完整比较结果。比较器记录滚动位置前检查 DOM 是否仍连接、恢复是否完成，脱离页面或恢复中的零值不能覆盖上次位置。

详情编辑器启用 fillHeight，在320×500等矮屏按实际剩余空间缩小内部 viewport，不能用独立编辑器的280px最小高度撑出裁切区域；滚到正文末尾仍须完整可达。模板等页面内嵌编辑器保留原有最小高度。

标题在正文上方编辑，按 Enter 或失焦通过属性接口独立保存；空标题、IME、失败重试与取消由 `RequirementTitleInput` 处理。标题下显示“已修改 · N 处/与最新版本一致”，点击变化数量循环定位正文标记。开启版本标记时，修改状态与标记共用 `useContentModified` 的一次 Diff；关闭后只按 `richTextContentKey` 进行轻量语义核对。输入先显示待核对，空闲 200ms 或最长 1.5s 核对最新正文，不延迟实际正文事务。标题、其他属性、版本说明不参与该提示。保存正文版本时记录当时已保存的标题，历史标题不改写。顶部草稿状态可打开同步和个人检查点详情，正式保存另有入口，三者保持不同语义。

编辑器每次有效正文更新只导出一次 JSON，BlockId 在事务内维护身份。已验证 ID 完整唯一的文档中，同一文字块内闭合的 inline ReplaceStep 及 AddMark/RemoveMark 直接沿用合法性；拆段、粘贴、列表/表格、未知步骤或未验证文档仍走完整检查。远端事务不静默重写身份，本地后续结构操作保留修复和原有撤销边界。

- 列表仅加载摘要及编辑人。所选历史正文按 ID 加载，复用最新版本及页面缓存；迟到响应不能覆盖选择，失败可重试，切页取消请求。
- 默认“只比较相邻版本”：改旧版联动下一版，改新版联动上一版；最新正式版的下一项是当前草稿。禁选没有前一项的最旧版作为联动目标。
- 关闭联动后自由比较，重新打开以旧版为基准。新 revision 到达时，草稿比较跟随最新基线；已选正式版本对保持不变。
- 版本选项展示版本号、时间；公开 detail/meta 与 option-detail 展示说明、保存人及去重编辑人，完整信息也进入可访问文本。缺少名单明确提示，不能用保存人代替编辑人。
- 旧 `view=history&revision=...` 转为该版相邻比较，最旧版取首个可比较版本对。历史快照不能覆盖当前正文。
- 人工和 AI 的变化共用版本比较；AI 仅持锁期间显示侧栏/窄屏提示及取消入口，旧审核页面跳转规则见 [Agent 文档](agent-editing.md#页面行为)。

## 正文版本标记

基线为最新正式版本，目标为已同步的共同草稿，包含本地、协作者和 AI 修改。`buildVersionMarkers` 只映射既有 Diff 对齐结果：顶层块独立标记，列表按直接 listItem/taskItem，图片与表格按整块；连续删除合并，记录当前正文中前后相邻 ID，文首、文末及没有相邻块时仍能定位。正式版本更新后重新核对，没有基线、模板页和比较视图不显示。

`richTextDiffSteps` 与 `buildRichTextDiff` 共用算法；正文核对按约 6ms 的预算在块之间让出主线程，单个块仍不可拆分。正文或基线变化会废弃未完成代次；停用、隐藏页面和进入比较时取消计算，恢复只处理最新正文。最近完成的标记可暂时保留，但待核对时禁止打开或恢复，避免使用过期快照。进入最新版本 → 当前草稿的比较时，按不可变正文对象身份复用同一结果，不重复 Diff。

`RequirementVersionMarkers` 位于 EditorContent 外，按 diffId 取得块 DOM，以边框盒为标记范围，不写 JSON、Yjs 或编辑历史。正文中相邻且同为新增或修改的块，在间距中点划分热区；完整连续区间只绘制一条竖线，避免独立线段在小数像素或缩放下出现接缝。未修改块、不同变更类型和删除位置会截断竖线。每个块仍保留独立标记、计数、预览和恢复，不把连续区间合成大 Diff。锚点使用 flex 布局、热区按钮绝对定位，避免 Tooltip 的行内基线使短标记下移；新增/修改竖线和删除短横线共用中心轴。

几何测量加入 `scheduleEditorGeometry` 的帧内先读后写调度；先连接完整布局，再筛选视口内标记，避免滚动边缘出现断线。滚动仅筛选缓存位置，正文结果、尺寸、字体、图片加载/缩放、布局动画变化时失效重测。隐藏时移除监听和观察器。标记与 AI 标注共用页边但分层避让，不能通过增加正文 padding 改变换行。

悬停、键盘聚焦、打开预览或定位修改时，当前块旁的竖条加粗，并在正文外绘制对应块的无描边浅色强调层；只测当前目标的 DOM，不向正文添加 class、mark 或事务。分隔线的强调范围读取编辑器当前普通正文行高，以横线为中心展开，避免仅覆盖1px横线。强调层不接管指针，正常动效轻亮一次后保持淡色，减少动态效果时静态展示。移开淡出，滚动清除原悬停目标，隐藏/停用/卸载清理浮层；删除项没有当前正文，不强调相邻未修改块。

卡片复用 `DiffBlockRenderer` 的字符、格式、表格和图片展示，并保留正文个人偏好。点击或正文右键菜单（ContextMenu / Shift+F10）打开；Escape、外部点击或锚点滚出视口时关闭，恢复经事务映射的原正文选区。比较入口传递 diffId，定位请求优先于该版本对之前的滚动位置。

单块恢复先用 `revertDraftChange` 得到目标，再通过编辑器普通事务替换最小变化范围，独立划分普通历史和 Yjs 撤销边界；不走外部正文装载，不重建 Yjs 历史。命中 AI 标注时走 `annotation-edit-guard` 的取消/确认流程；只读不显示恢复，AI 锁、上传未处理和其他忙碌状态禁用并解释原因。删除项所属列表整体消失时，按父块相邻 ID 重建列表容器；列表类型、起号等共享属性随容器恢复，保留其他列表项和当前容器 ID。撤销新增的最后一块时保留合法空文档，不恢复无关历史内容。

“设置 → 阅读与编辑 → 显示版本标记”默认开启，通过现有偏好 Cookie 保存。关闭后取消 Diff 与浮层测量，保留原有正文修改提示。无头交互、双页 Yjs 和长文开关对照入口见 [开发文档](development.md#按改动选择验证)，测量结果见 [REQ-27 验证记录](req-27-version-markers-validation.md)。

## 提示块

`callout` 保持 `inline*`、稳定 diffId 和 `section[data-requirement-callout][data-tone]` 的 HTML 格式。`tone` 省略默认 note；写入只接受 note（说明）、tip（建议）、warning（注意）、danger（风险），网页、模板、AI 共用校验。旧缺失或未知值展示为说明，不在读取或渲染时改写 JSON/Yjs/历史。收紧校验前的生产全量取值检查见 [REQ-30 验证记录](req-30-callout-validation.md)。

四类沿用正文蓝、成功绿、警告黄和鲜红 `--bing-red-500`。背景为语气色8%与正文底色混合，1px边框24%，8px圆角，内距12px/16px、左侧44px；移除粗左边框。18px图标对齐首行，正文仍用普通文字色，字体/字号/行高/宽度/亮暗文字偏好继续生效，links、highlight、Diff 状态色保持各自语义。编辑器、正式版只读、完整 Diff、选区历史和设置预览共用展示。

“更多格式工具 → 组件块”子菜单插入四类空块；替换空段或在非空段后插入，选区进入块内，类型占位只显示在视图中。NodeView 的图标区域 contenteditable=false，不进入复制、选区和纯文本；HTML 序列化不包含按钮和图标。可编辑图标及右键/ContextMenu/Shift+F10 的“切换提示类型”子菜单使用 BingDropDown，当前项带勾。菜单按 diffId 重新定位，只改 tone，保留文字、marks、身份和选区；普通历史与 Yjs 都独立划分前后撤销边界，AI 锁/只读/停用时关闭入口。

整体标注的 tone 属于有效内容，变化经过 annotation-edit-guard；取消不改正文，确认只重放一次隔离历史事务。纯语气变化计为 modified，Diff 补充“语气：说明 → 注意”等提示，恢复使用基线原语气。Diff 按 inline* 连续提取提示块内容，保留真实 hardBreak 和空白，不在不同 marks 的文字之间添加换行。BubbleMenu 首次注册触发 Yjs 重绘时，Vue Editor 与 view 的插件集可能短暂不同；编辑器创建后用无历史空事务完成同步，避免首个用户修改被初始化重绘覆盖，不重建共同文档。

## 任务清单

使用官方 `@tiptap/extension-list` 的 TaskList、TaskItem，网页 NodeView 只扩展交互展示。`taskList` 内容为 `taskItem+`；`taskItem` 内容为 `paragraph block*`，允许嵌套任务及普通列表。两类节点都有稳定 diffId，`checked` 只接受 boolean、省略视为 false。勾选属于正文语义，参与“已修改”、Yjs、快照和模板；正式版本保持不可变，不回写旧 JSON 或重建共同编辑历史。`extractPlainText` 逐项生成 `[ ] 文字` / `[x] 文字`。

工具栏列表组、右键段落转换及斜杠菜单提供“任务清单”。行首 `[] `、`[ ] `、`[x] ` 转换为清单；Enter 拆项且新项默认未勾选，空项 Enter 退出，Tab/Shift+Tab 嵌套/提升。Markdown 粘贴和导出采用 GFM `- [ ]` / `- [x]`，HTML 序列化保留 data-type/data-checked 与嵌套结构；复制正文文字不含控件，粘贴为新块时重新分配 ID。

复选框使用 BingCheckbox 的 decorative 展示，由外层键盘可聚焦控件提交正文事务；16px、4px 圆角，对齐文字首行。点击与空格操作保留文字选区，前后都隔离普通历史/Yjs 撤销边界；事务被标注保护拒绝时不提前改变控件状态。已勾选正文使用次级色，不自动加删除线，子项保持自己的状态。AI 锁、只读、停用、正式版、完整 Diff 与选区历史不提供勾选操作。

Diff 按直接 taskItem 对齐；纯状态变化计为 modified，通过两侧复选框状态与差异底色展示，不另加勾选说明文字；嵌套列表和表格内任务递归展示。回退恢复基线状态、条目及合法列表结构。选区历史沿用相同展示方式并跟踪所选任务的状态，选区外嵌套任务的勾选不算文字范围变化。文字 AI 标注沿 taskList/taskItem 容器定位到内部段落，勾选不使原文字范围失效；注册与 Agent JSON 规则见 [节点标注能力](annotation-nodes.md) 和 [Agent 文档](agent-editing.md#格式与图片)。

## 折叠块

REQ-36 使用官方 `@tiptap/extension-details`，固定结构为 `detailsSummary detailsContent`；摘要承载 `text*`，内容区承载 `block+`，可嵌套列表、表格、图片及折叠块。`details` 和 `detailsSummary` 各有稳定 diffId，结构层 detailsContent 没有 ID。共享 schema 拒绝未知属性、缺失内容区、空内容区或错误顺序。`open` / `hidden` 不属于正文属性，不能通过 API 写入。

扩展配置 `persist: false`。网页 NodeView 默认收起，将状态保存在编辑器会话内的 diffId 映射中；重绘、切换标签、文字撤销和远端更新保留本机状态。切换仅修改 DOM，不创建正文事务、撤销步骤或 Yjs 更新；只读正文同样可展开。工具栏“更多格式工具 → 组件块”和斜杠菜单可创建，工具栏“取消折叠块”保留摘要、内部正文及各自 ID。原生三角按钮支持 Enter/Space，空摘要显示“折叠块标题”。

折叠块整体使用 1px 中性色边框、8px 圆角和正文底色，摘要栏使用浅色背景、600 字重及上下 10px 留白；收起时仍呈现完整区域边界。展开内容接在同一外框内，以横向细线分隔、上下 12px / 左右 16px 内距呈现，首尾块不叠加外边距。编辑态、只读、完整 Diff 与选区历史共用这套样式，嵌套块保留各自边界；亮暗主题及正文偏好继续生效，减少动态效果时取消三角旋转过渡。

键盘行为按本机展开状态判断可见性，不能使用 `offsetParent` 判断 until-found 的内容：收起摘要 Enter 在容器后续写，展开摘要 Enter 在内容区新增段落；内容末尾空段 Enter 退出，稳定 diffId 不影响空段判定。方向键和选区修正避免光标进入隐藏内容。

内容区使用 `hidden="until-found"`，`beforematch` 展开命中的全部折叠祖先；不支持该值的浏览器按普通 hidden 收起。目录保留隐藏标题，点击目录、章节链接、AI 文字/节点标注、版本标记及选区历史返回正文时先展开再测量滚动；隐藏内容不参与当前标题或标注几何计算。整块定位同时展开其中的折叠内容。

纯文本包含摘要与所有正文，摘要的不同 marks 不插入额外换行。HTML 使用官方 details/summary/div[data-type=detailsContent] 结构，序列化不包含按钮和展开状态；复制粘贴重新分配 ID。Markdown 使用嵌套的 `:::details`、`:::detailsSummary`、`:::detailsContent` 容器，每层用 `:::` 关闭，导出不携带 ID 或视图属性。尾段规范化和模板复制沿用递归规则。

完整 Diff 固定展开，先分别比较摘要与内容区，再按内部稳定 ID 递归对齐；列表及表格中嵌套折叠块同样展示。草稿回退恢复整个比较块的合法子树及原 ID。选区历史独立跟踪摘要与内部正文块，摘要保留相同字重与展开标记。AI 整体标注以 details 为目标，文字标注以摘要或内部文字块为目标；Agent 修改内部内容时替换所在顶层块并保留各层存活 ID。无需数据库迁移，不改写旧 revision 或重建 Yjs 历史。

## Diff 计算与展示

`buildRichTextDiff` 的处理顺序：

1. normalize 顶层块；列表按直接 listItem/taskItem 的 diffId 拆分，保留列表类型、起号及父 ID。
2. 优先按 diffId 对齐，前视识别增删；ID 无法对应且类型相同才按位置配为 modified。
3. 属性签名排除 diffId 和空属性、稳定键顺序，规范图片 align，并保留嵌套块的类型、属性及结构。
4. 文本按 Unicode 字符与 hardBreak 分 token，比较规范化 marks；字符 LCS 的两侧数量乘积超过 50,000 时退回前后缀算法。
5. 表格再按行列位置比较单元格的文本、属性、格式和子节点结构（包括嵌套任务状态）。

Mark 顺序不产生差异；link 比较 href/target，highlight 比较 color，其他 mark 比较非空并排序后的 attrs。hardBreak 必须渲染为真实换行。图片属性和题注分别参与比较，空题注回退 alt/“图片”；尺寸差异两侧用相同缩放系数保留比例，不压成同样大小。

`RichTextDiffViewer` 与选区历史使用自定义只读 renderer，不创建两个可编辑 Tiptap 实例。普通长词、数字和单元格内容允许折行，代码保留空白并独立横滚。新增节点必须覆盖只读安全渲染。

展示约束：

- 并排/统一共用 useDiffLayout；比较容器可用宽度<860px默认统一，用户选择优先，监听容器变化而非只看窗口。“仅变化”只筛展示，不改变计算、追溯或回退范围。
- 可折叠长 unchanged 区域、合并相邻增删 hunk；统一视图先旧后新。
- 小地图在正文滚动区外，按全文位置显示状态短线，滚动前也能定位文末；布局、筛选和尺寸变化后重测。
- 文档比较页的当前变化用左侧3px蓝线和浅蓝中间操作区定位；独立比较及选区历史保留2px内描边。标记不占布局、不拦截点击，进入时强调600ms，减少动态效果只保留静态标记。
- 中间操作栏用 `+`、`−`、`~` 表示新增、删除、修改。符号与回退按钮共用同一位置，悬停、定位当前变化或键盘聚焦时切换为回退按钮；触屏直接显示按钮，只读比较保留符号。二者不纵向叠加，单行正文与任务项不因操作栏额外撑高。
- 导航循环切换，关闭按钮点击节流；通过公开 viewport/scrollTo 只滚当前容器，不使用会牵动页面的 scrollIntoView，不叠加 CSS scroll-behavior:smooth。
- fillHeight 仅用于有明确可用高度的工作区；版本选择与比较操作共用固定工具栏，正文占剩余空间。并排列标题位于正文滚动容器内，纵向固定、横向跟随列对齐；变更定位预留标题高度。窄屏比较至少320px，过矮窗口由外层页面滚动。
- `RichTextDiffViewer` 接受暂未加载的空版本值，保持工具栏和选择状态，通过 placeholder 插槽展示加载、失败或无版本提示；版本未就绪时不计算部分差异或显示零值统计，正文恢复后重新观察内容尺寸。
- 仅目标为当前草稿时可发出 revert-change。

## 选区历史 Diff

入口来自选区菜单、右键及工具栏；没有文本选区时追踪光标所在逻辑文字块。无法可靠表示为连续文字的表格、分隔线等不猜测，提示重新选择。

`buildSelectionHistory` 必须沿“捕获草稿 → 最新正式版本 → 更旧版本”的**完整相邻链**投影范围：

- 顶层文字块拆成 segment，列表以直接 listItem/taskItem 为逻辑块；先按 diffId，再比较块内字符、hardBreak 和 marks。
- 同块选区外的变化不算选区变化。拆分或 ID 缺失时，仅同类型旧块唯一匹配文本才继续，并标为 inferred；无法定位即停止猜测。
- “仅更改”只过滤最终展示，中间无变化版本仍须参与投影；格式、链接目标和高亮颜色也是变化。
- 修改人按整个节点统计，可能修改了选区外内容或修改后撤销；保存人与节点参与者分开。缺失记录标为未记录，不提供逐字作者或输入时间。

`/selection-history/:id` 在独立只读标签页打开。原页把选区、当时草稿和节点名单写入随机 token 对应的同源一次性存储，有效 24 小时；新标签页消费后转存 sessionStorage 并删除共享副本，刷新仍可恢复。正文不放进 URL 或服务端。

本机上下文有效后才请求 `includeContent=true` 的完整历史；无效上下文不预取正文。捕获时未确认编辑须提示同步后重开，不能用后来名单覆盖捕获快照；旧逐字元数据可忽略而继续展示选区。

页面按内容自然增高，Diff 和版本表格仅设最大高度，短内容不撑满视口。复用完整 Diff 的状态色、描边、导航、图片预览和只读 marks；不提供修改历史或回退命令。“完整比较”在当前标签页进入版本对，原编辑页不变。

## 草稿变更撤销与扩展检查

`revertDraftChange` 只改克隆后的草稿：inserted 删除目标节点，deleted 从基线克隆并按相邻 ID 恢复，modified 用基线节点替换；嵌套列表按父/子 ID 定位并清理空列表。基线 revision 不可变，操作结果通过协作同步。

新增或修改节点时同时检查：JSON/attrs → 运行时与 HTML/Markdown → 服务端 schema → 旧数据兼容 → 纯文本 → Diff → 只读 renderer → 撤销 → 资源引用/GC。改变对齐、fallback ID、列表分组或 LCS 边界时补相应回归。

## 代码块头部与语法高亮（REQ-31）

代码块沿用 `codeBlock`、`attrs.language` 和稳定 `diffId`，增加可选 `attrs.title` 名称。编辑器和服务端共用 `NamedCodeBlock` 属性定义；名称默认为 null，最多 120 个 UTF-16 单元，不允许换行或控制字符，旧文档缺少名称时继续正常读取，缺省值不制造版本或选区历史差异。名称不参与原文复制和 `contentText`，HTML 通过 `data-code-title` 保留名称，富文本复制粘贴、Yjs 和正式快照均保留该属性；无需数据库迁移，不改写历史。

Vue NodeView 的头部最小高 52px，上下留白 9px，使用 32px 控件；`contenteditable=false` 区域依次放置可搜索语言选择、可选名称输入框和复制按钮。代码块宽度不超过 420px 时名称换到第二行。名称按 Enter 或失焦确认并独立撤销，Escape 放弃本次输入，中文组词不误提交；只读正文、完整 Diff 与选区历史显示名称、语言标签及原文复制。头部控件和 token 不进入序列化内容；语言通过单独历史事务修改，纯文本写入 null；旧语言别名仅在展示和高亮时规范化，读取旧正文不改写属性。

高亮复用 `@moubing/bing-ui` 的包根公开 API（`getCodeLanguages`、`normalizeCodeLanguage`、`resolveCodeTheme`、`highlightCode`），不直接导入或复制组件内部 Shiki 模块。只有进入视口或接近视口的代码块才申请高亮，正文变化后等待 150ms；以语言、主题和原文缓存，最多 32 项或 2 MiB 文本键。仅通过 ProseMirror Decoration 应用颜色，保持字体、字重、行高和光标几何。组词中的当前块、隐藏页面、停用编辑器不申请或应用异步结果；恢复后丢弃过期结果。读取 UTF-16 偏移并校验 token 能还原原文，CRLF 使用原文字节对应的字符位置。

超过 2,000 行或 100 KiB UTF-8、纯文本、未知语言及加载失败均保留原文。亮暗自动主题和 BingCodeBlock 一致，个人代码字体、段落字号/文字色和行高继续优先。版本比较和选区历史只添加头部，不添加语法颜色，保留新增绿、修改琥珀黄、删除鲜红及行内 Diff；设置预览和只读历史使用同一高亮调度。

## 标题章节链接

REQ-32 使用标题现有的稳定 `diffId`，链接格式为 `/requirements/<文档 ID>?block=<标题 diffId>`。H1–H3 悬停或折叠光标进入时显示 `#`，右键、ContextMenu 和 Shift+F10 也可复制；只读正文、版本比较和选区历史复用相同复制入口。比较及选区历史的按钮固定在标题末尾，避免占用中间变更操作栏。历史标题链接指向当前正文，已删除或已转换为非标题的块按失效章节处理。模板和设置预览没有文档身份，不生成虚假链接。

`RequirementChapterLinks` 在正文 DOM 外绘制按钮与背景强调，不写 Tiptap JSON、Yjs 或历史事务。仅测量当前标题，复用几何调度器，并随编辑器停用取消监听、测量和强调计时。桌面将原有 64px 左右留白重新分配为 44/20px，保留正文可用宽度和标题换行；版本标记贴正文，`#` 在外侧。AI 编号仍优先，按钮通过纵向或外侧位置避让；窄屏及剩余空间不足时显示在标题末尾。

详情页由 `useRequirementChapterLink` 消费路由意图，正文就绪及首次字体排版稳定后，复用目录的 ScrollToPlugin 和 28px 顶部间距。只滚动正文 viewport；定位期间暂停阅读锚点捕获和恢复，包括已经排队的写入，字体或侧栏继续排版时从当前位置平滑续接新的目标坐标，不能用旧锚点终止动画。到达后标题显示约 900ms 无边框浅底，轻微亮起后淡出；目录点击也复用这一提示，从强调区域实际挂载后计时。减少动态效果时直接定位、静态强调。`block` 优先于初始 `view=diff` 和阅读位置恢复，用户点击、滚轮或键盘操作取消尚未完成的定位。缓存实例记住已消费的参数，新 `block` 重新定位，返回同一旧链接不重播。

正文自身关闭浏览器滚动锚定，不能只在 BingScrollbar 的外包装上设置：嵌套 viewport 仍会独立选择锚点。浏览器扩展追加辅助 DOM 属性可能触发 ProseMirror 重绘，此时滚动和到达提示按稳定 diffId 重新取得标题节点，避免自动回跳或因旧节点断开而中止。真实输入引起的 DOM 变化仍交给编辑器处理，不过滤扩展属性、不修改正文或选区。

失效参数先定位文首并提示“该章节已不存在”，通过 `router.replace` 清除 `block`；同时清理会重新打开比较的旧 `view` 值，保留其余参数。读取 URL 时按属性值匹配标题，不把外部 ID 拼入 CSS 选择器。定位不改变编辑器选区；阅读锚点在定位完成或取消后采纳当前位置，包括尚未启动滚动就被取消的情形。
