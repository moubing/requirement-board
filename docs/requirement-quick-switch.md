# 文档快速搜索、切换与最近浏览

有项目访问权的账号可在固定 Header 右侧使用搜索和「最近浏览」，覆盖四种文档。登录、注册和邀请使用简化 Header。桌面搜索输入框常驻 Header，点击或使用 Ctrl/⌘ K 直接聚焦，输入后向下展示候选；≤700px 保留图标入口，点击后在 Header 下方展开输入。搜索和最近浏览浮层互斥，切页收起候选并保留查询文字。外壳宽度和排版见 [UI 规则](ui-rules.md)。

## 组件与数据

最近浏览与窄屏搜索入口复用 Header 的 ghost/lg 按钮，快捷键在搜索提示和输入占位中按系统显示 Ctrl K 或 ⌘ K；最近浏览从入口下方向左展开。搜索输入使用 npm 包的 `BingAutocomplete`（lg）：`v-model` 管理查询，`filter=false` 接收业务候选，`openOnEmpty=false` 禁止空值展开，`completeOnSelect=false/closeOnSelect=false` 让业务在导航成功后关闭。最近浏览复用 BingDropDown、BingDropDownItem 和 BingScrollbar；组件版本查阅见 [bing-ui 接入](bing-ui.md)。

候选面板与 BingSelect 共用进出和悬停动效，详情跟随鼠标或键盘高亮，跨面板空隙时保留，靠近屏幕边缘自动换侧，窄屏在候选下方独立展示。中文组词期间保留平滑光标和当前候选，确认后才更新查询，避免输入拼音时反复筛选。

快速搜索按输入调用 `GET /api/requirements/search`，160ms 合并连续输入；空查询不请求。查询结果和按 ID 摘要由 `useRequirementCache` 按账号及固定项目隔离，最多复用 60 秒。相同条件请求合并，途中失效顺序补读；切换查询或关闭面板取消旧请求，序号防止迟到响应覆盖新结果。新建、正式保存和属性修改失效查询；网络失败保留查询并提供重试，不等同于文档不存在。

标题独立保存成功后立即更新本机摘要显示并使搜索失效，匹配仍由服务端完成；收到该 ID 的新服务端摘要后清除旧覆盖。输入中的未提交标题不参与搜索；搜索没有独立数据库模型。

## 匹配与导航

匹配规范位于 `shared/requirements/search.ts`，数据库查询实现相同规则。全范围搜索及摘要 HTTP 入口见 [文档查询](requirement-queries.md)，不依赖列表当前页。

- 仅匹配需求号、名称，支持单字、中文片段、大小写不敏感、空格分词和 `REQ-7` / `req7`；各词都要匹配。负责人、状态和内部 ID 不参与检索。
- 排序依次考虑编号完全匹配、编号前缀、名称前缀、包含；同等匹配按最近访问、更新时间及稳定 ID 排列。
- 候选为 `REQ-7（名称）`，最多 20 条，详情显示完整名称及状态、优先级、负责人、报告人、更新时间。空查询或纯空白不展示候选、历史或空结果面板；首次聚焦和快捷键聚焦只定位输入框，输入文字后展开，清空后收起。最近浏览仍由独立按钮提供。
- 方向键选择，Enter 打开，Escape 关闭；Ctrl/Cmd+K 聚焦搜索，快捷键提示位于 placeholder，中文组词和模态框期间不抢焦点。窄屏清空后保留输入焦点，可继续输入；Escape 和关闭按钮也能收起空搜索框。在详情工作区重复选择当前需求只关闭面板；其他页面即使带有同名 `id` 参数（例如选区历史），仍正常进入需求正文。
- 「查看全部搜索结果」传递 `/requirements?q=...`；列表继续支持状态、负责人、分组和分页。
- 点击或 Enter 立即发起详情路由导航，不再在 Header 预读完整正文。通过账号校验与当前文档离开保护后先展示目标详情页框架，详情及元数据在页内加载；两者成功后才创建协作工作区。慢请求显示骨架，首次加载失败或文档不可访问时在目标页提供说明、重试及返回列表入口。查询文字保留；离开保护覆盖路由参数变化及离开路由，完整备份与失败边界见 [drafts.md](drafts.md#离开或切换需求)。
- 加载框架与工作区共用编号及视图导航，立即显示搜索/列表摘要中的目标编号；没有摘要时保留等宽空位，不临时换成“文档详情”。编号区固定占位，正文/版本比较标签不随编号位数或加载阶段左右移动；加载期间标签不可操作，返回列表入口可用，正文工具栏先以禁用状态占位。摘要只用于显示身份，详情授权与协作初始化仍等待正式响应。
- 每条搜索结果右侧提供「在新标签页打开」图标按钮，立即打开该文档，包括当前文档；原页面、草稿和查询保留。点击结果本身或在输入框按 Enter 始终在当前页导航，不提供全局勾选模式。输入框按 F2 可进入当前行按钮，按钮内上下键切换、Enter / Space 激活，左键返回输入。新标签页独立执行原有认证、详情读取与草稿恢复，并隔离 `window.opener`。此入口使用 `bing-ui` 0.19.0 的 `optionActionLabel / option-action`，默认运行和测试均使用 npm 正式包。

## 最近浏览与阅读位置

`useRecentRequirements` 在详情及草稿成功恢复后记录访问，保留最近 20 个不同需求。悬停、未成功的导航和同一需求内切换视图不新增记录。选项辅助说明只显示浏览时间，当前项保留高亮与无障碍标记，不额外显示“当前需求”文案；清空只清除导航历史。

localStorage 键为 `rb:recent-requirements:v1:<账号 ID>:project_main`，只保存版本、清空时间水位以及 `{ id, visitedAt }`，名称和属性从按 ID 摘要派生。打开最近浏览时由 summaries 一次核验至多 20 个 ID。只有成功响应的 complete、requestedIds 和 unavailableIds 能清理本次确认不可访问的条目；列表/搜索某页缺少 ID、请求失败或取消均不能删记录。多标签页通过 storage 事件合并，清空水位阻止旧事件恢复已经清掉的记录；存储不可用时保留会话记录。

`useRequirementReadingPosition` 在当前标签页内按账号和需求记录正文滚动坐标，最多保留 100 项，跨页返回时恢复且不主动聚焦正文。该状态不写入草稿、正文或 localStorage，不跨设备同步。

## 验证入口

- `tests/diff/requirement-quick-switch.test.ts`：字段边界、排序、记录解析与合并。
- `tests/diff/requirement-navigation-state.test.ts`：并发请求、失效、账号隔离、存储失败及跨标签清空。
- `tests/diff/draft-lifecycle.test.ts`：可等待备份、失败阻止导航、原始事件、图片 Blob 和保存锁。
- `pnpm test:browser`：隔离数据下的真实编辑与切换，运行配置见 [development.md](development.md#需求切换的浏览器验证)。
- `BROWSER_TEST_SCENARIO=search pnpm test:browser`：挂起详情/元数据仍先进入详情页，逐帧核对加载/失败重试/缓存返回时的目标编号及导航横坐标，另覆盖无权/失效目标、草稿恢复、新标签页真实加载与亮暗窄屏。
