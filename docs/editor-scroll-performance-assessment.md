# 编辑器滚动性能评估

测量日期：2026-10-02；应用基线 `3aadeb3`，组件基线 bing-ui 0.9.1。本文保留历史隔离实验与 0.9.3 结果。2026-10-19 的真实 Nuxt、REQ-8 原图及缓存生命周期验证见 [REQ-10 验证记录](req-10-performance-validation.md)，不要混用两次实验的计量口径。

## 历史结论与状态

| 问题 | 证据与状态 |
| --- | --- |
| Cursor 切换形状引发大范围样式重算 | 0.9.1 隔离实验确认；0.9.3 已改为预生成规则并缩小标记范围，应用已升级 |
| contenteditable 内标记导致段落反复重建 | 0.9.2 集成发现；0.9.3 只标记编辑根节点，已有段落 DOM 稳定性回归 |
| 隐藏目录仍扫描标题与测量坐标 | 2026-10-05 已暂停隐藏、非活动及窄屏目录的监听和测量；功能回归通过，未量化性能收益 |
| 图片悬停动画与交互子树的渲染开销 | 隔离对照支持，尚未完成针对性优化 |
| 长文档及真实图片页面性能 | 仍需完整页面复测，不能据以下样本承诺稳定 60 fps |

现有证据指向样式重算与悬停渲染，不支持优先重写 Tiptap、协作模型或采用全文虚拟化。坐标读取可能结算此前的样式失效；火焰图中测量函数耗时高，不代表它制造了全部开销。

## 诊断样本与因果证据

原页面有 24 个顶层块、9 个标题、5 个段落、10 张图片，正文 870 个 DOM 后代，高约 5,459 px。用户仅提供 Performance 截图，未取得原始 trace，无法逐函数解释原页面耗时。

无头 Chromium 148.0.7778.96 中挂载真实编辑器、NodeView、应用样式及本地 Y.Doc/Awareness；按原正文结构重建样本，图片替换为同尺寸 SVG。视口 1,060 × 962、DPR 1.25，无 CPU 降速；字体、图片和焦点稳定后，从 scrollTop=700 开始，鼠标固定，向下和向上各 40 次滚轮请求，位移 75、间隔 35 ms，最后等待 500 ms。

| 隔离设置 | 时长 | 样式重算累计 | 每秒样式重算 | 单次峰值 |
| --- | ---: | ---: | ---: | ---: |
| 原行为，两轮基线 | 6.92 / 7.05 s | 605.5 / 643.2 ms | 87.6 / 91.2 ms/s | 15.5 / 14.7 ms |
| 移除 BingCursor | 6.17 s | 251.5 ms | 40.8 ms/s | 2.4 ms |
| 保留 Cursor、固定形状 | 6.24 s | 267.3 ms | 42.8 ms/s | 2.3 ms |
| 停用目录与平滑文字光标测量 | 7.09 s | 620.1 ms | 87.4 ms/s | 14.1 ms |
| 关闭图片节点内 CSS 动画与过渡 | 6.12 s | 410.7 ms | 67.1 ms/s | 16.5 ms |
| 移除 Cursor 并关闭图片动画 | 6.10 s | 89.0 ms | 14.6 ms/s | 1.4 ms |

累计值取 CDP `RecalcStyleDuration`，峰值取 trace `UpdateLayoutTree`，计量边界略有差异。固定形状仍保留 Cursor 监听和命中检测，却接近移除组件的结果，支持“动态改写全局 cursor 规则是主要失效来源”。停用坐标测量后总体开销仍在，不能把测量点直接当作根因。

图片实验同时影响工具栏、按钮和缩放控件，不能把全部收益归给某一条 transition。纯滚动期间正文 update/transaction 为 0，累计 Layout 约 0.5–0.9 ms；这不覆盖打字、粘贴或远端同步。

## 最终修正与 0.9.3 测量

0.9.3 预生成 16 种状态规则，普通区域标记命中元素；contenteditable 只标记编辑根，通过固定 `:hover` 规则显示内部光标。0.9.2 曾给段落添加属性，触发 ProseMirror DOMObserver 反复重建，因此该中间候选的 55% / 58% 数据不作为交付结论。仅检查 JSON 和 transaction 不足，还须验证原段落节点仍连接。

最终夹具为 12 个段落与 12 张 720 × 320 SVG，长样本扩大五倍。使用同类真实组件、无头 Chromium、1,060 × 962 视口和 DPR 1.25；稳定后向下/向上各 20 次，位移 75、间隔 35 ms，最后等待 300 ms。CDP 指标差值统计样式与布局，rAF 采样间隔。此表只能在组内比较，不能与前表混算收益。

| 规模与 Cursor | 时长 | 样式重算累计 | rAF 间隔 P95 | 大于 50 ms 的间隔 |
| --- | ---: | ---: | ---: | ---: |
| 24 块，0.9.1 发布包 | 3.583 s | 425.6 ms | 16.7 ms | 0 |
| 24 块，0.9.3 最终源码 | 3.171 s | 232.0 ms | 16.8 ms | 0 |
| 24 块，0.9.3 发布包 | 3.182 s | 213.6 ms | 16.7 ms | 0 |
| 120 块，0.9.1 发布包 | 4.183 s | 1,432.2 ms | 66.7 ms | 16 |
| 120 块，0.9.3 最终源码 | 3.581 s | 768.5 ms | 33.3 ms | 0 |

小样本累计样式重算减少约 45%–50%，长样本约 46%；按时长折算，每秒分别减少约 38%–44% 和 37%。累计布局时间为 0.45–0.63 ms。发布包检查确认滚动前后 JSON 不变、transaction/update 为 0、16 条规则不变、段落节点稳定，输入和撤销正常。

## 复测边界与入口

- rAF 间隔不等于最终呈现帧质量。长样本 P95 仍为 33.3 ms，不能宣称任意长文档稳定 60 fps。
- 样本使用 SVG 占位图和本地协作对象；未覆盖原 PNG 解码、GPU/内存、完整业务面板、真实协作网络及生产构建差异。
- Playwright 输入被识别为高精度输入，没有启用实体鼠标的平滑滚轮插值，不能据此排除该路径的开销。
- 后续保留原图片，在相同视口、焦点、输入设备与滚动路线下至少测三轮完整 trace，同时看呈现帧、样式峰值和主线程占用。
- 再按证据评估图片工具栏按需挂载、悬停动画和可见目录的测量缓存；引入虚拟化前须验证选区、输入法、拖选、查找及目录定位。

行为回归使用 `pnpm test:browser:editor`、`pnpm test:browser:workspace`；目录暂停由 `tests/diff/requirement-outline-visibility.test.ts` 覆盖。这些功能测试不替代性能测量。相关实现为 [目录逻辑](../app/components/editor/use-requirement-outline.ts)、[图片 NodeView](../app/components/editor/RequirementImageNode.vue)；组件库修改遵循 [bing-ui 接入](bing-ui.md)。
