# UI 规则

本规则对应当前固定 Header 与可收起导航界面，适用于工作台、文档列表、模板、成员、文档编辑和账号页。

## 导航与布局

- Header 固定 64px 并横跨整个窗口。左侧为导航开关和品牌，右侧顺序为搜索、最近浏览、新建文档、设置、账号。新建与设置同为 ghost/lg 普通按钮，>1000px 显示图文，≤1000px 同时隐藏文字并保留名称与提示。极窄屏隐藏品牌以保留全部操作。
- 桌面导航在 Header 下方占 224px，收起后占位为 0；亮色背景为白色，和正文以边线分隔，暗色沿用深灰。桌面占位、内部内容与移动抽屉共用 `--app-sidebar-width`。只放工作台、文档、模板管理、成员管理，成员入口继续遵循原权限。`rb-sidebar-open` Cookie 保存桌面开合偏好；临时移动开合不覆盖它。当前项目固定，不增加项目切换器。
- 窗口 ≤700px 使用左侧覆盖导航，正文占满宽度。原生模态 dialog 负责背景 inert 和 top-layer，业务补充 Tab/Shift+Tab 循环；Escape、遮罩和关闭按钮可退出，恢复 Header 开关焦点。跨断点关闭抽屉，桌面沿用原偏好。实现依据见 [HTMLDialogElement.showModal](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal)。
- `AppShell` 只在一个网格占位上用 GSAP 改变宽度，导航内容使用 transform/opacity；快速反向从当前进度继续，减少动态效果直接到终态。收起导航立即 inert；断点和卸载清理动画。开合不重建 NuxtPage、正文或协作状态，不触发业务刷新。
- 手动开合侧栏保留 240ms 动画；登录、登出或路由权限导致的导航显隐直接使用目标宽度。认证中间件把本次权限结果交给目标路由，导航确认后与页面一起提交全局身份和缓存边界；等待期间保留原页面布局，不让旧工作台先收起侧栏或重建为加载态。退出接口失败保留原页面；导航取消不能应用候选账号，已成功退出但跳转失败/取消时仍清除本地身份。
- 导航整行可点，桌面至少 40px 高、18px 图标、10px 图文间距，触控环境至少 44px。导航通过 NuxtLink 的 custom 插槽使用 BingButton（ghost/lg/block），保持链接角色、当前页标记、路由守卫及修饰键/中键新标签页；不嵌套链接和按钮。选中项使用浅蓝底，悬停、按下与焦点效果复用按钮组件。Header 操作同样复用 BingButton，浮层继续使用已有菜单与搜索组件。
- 桌面搜索输入框直接常驻 Header，点击或 Ctrl/⌘ K 聚焦后输入；≤700px 改为图标入口，在 Header 下方展开输入。最近浏览和账号向下展开并避让视口；搜索候选与最近浮层互斥，关闭候选不隐藏桌面输入框。登录、注册、邀请及无项目访问权账号使用简化 Header，不请求创建元数据或文档索引。
- 新建表单只在 Header 挂载一次。`useBoardMeta` 按账号/项目共享元数据、合并请求；未就绪时加载或禁用，失败可原位重试，权限失效清空。工作台与文档页移除顶部标题/说明/新建/刷新行，错误重试仍保留；列表视图与数量置于筛选面板内。其他页面保留自身必要操作栏。
- `AppPageScrollbar` 管理 Header 下方内容滚动；侧栏不参与页面滚动，表格横向滚动限制在表格内部。
- 正文、模板预览和表格按各自内容排版；不用等尺寸卡片填满页面，不展示未接入的图表占位。

## 字体、颜色与间距

AI 标注复用右侧辅助面板第三个页签，编号和高亮为不占空间的浮层。添加、删除、选中标注不能改变正文宽度、换行、行高和段落间距；侧栏关闭时仍使用贴近选区的输入框填写要求。标注列表可编辑、删除、定位，底部提供整体要求、批量复制与内容预览。

- 延续 Maple Mono NF CN，回退到微软雅黑、Segoe UI 和系统无衬线字体。界面基准 14px / 1.5，辅助信息至少 12px。
- 文档标题 28px，窄屏 24px；正文默认 16px / 1.8，正文 H1/H2/H3 为 24/20/18px。窄屏不缩小正文。正文左对齐，阅读列居中。
- 新用户正文默认最大宽度 880px（包含内边距），可通过设置在 640–1800px 内调整。原有 Cookie 中的有效宽度、字号、颜色和行高继续生效；文档标题跟随正文字体，标题字号和界面控件保留各自样式。
- 使用 4、8、12、16、24、32px 间距；普通控件至少 36px，触控目标至少 44px，文档列表行高 56px。一般控件圆角 6px，弹窗 8px；文档编辑工作区不增加外层圆角卡片。

| 语义 | 亮色 | 暗色 |
| --- | --- | --- |
| 内容背景 | `#FFFFFF` | `#191D22` |
| 导航背景 | `#FFFFFF` | `#222830` |
| 次级区域背景 | `#F4F5F6` | `#222830` |
| 分隔线 | `#D8DDE3` | `#414B58` |
| 正文 | `#20242A` | `#EDF0F5` |
| 辅助文字 | `#56616F` | `#BAC4D1` |
| 导航选中与强调 | `#315FC4` | `#A2BEFF` |

主操作使用组件库的实色按钮，辅助操作用次要或无背景按钮。状态始终配文字，不能只靠颜色说明状态；详情页的目录、文档信息和 AI 标注使用 soft 分段页签，浅灰容器中以白底蓝字标记当前项。

## 正文节点

编辑器、历史只读、版本比较、选区历史和设置预览共用 `main.css` 的正文语义变量：`--rb-body-accent` 引用界面强调色，分隔线、引用文字、次级区域、行内代码和选中描边分别使用 `--rb-body-divider`、`--rb-body-quote`、`--rb-body-region`、`--rb-body-code-bg` / `--rb-body-code-border`、`--rb-body-selected-outline`。正文相关交互不再引用旧天蓝色 `--rb-blue`。链接、光标、选区与选中描边使用界面强调色；版本变化状态保持新增绿色、修改琥珀黄色、删除鲜红色，后续需求沿用这套约定。

- 段落默认 16px / 1.8，下方14px。H1 为24px / 1.4、700字重、上40下12px；H2 为20px / 1.5、700字重、上32下10px；H3 为18px / 1.5、600字重、上24下8px。首块无上间距，个人字号、颜色和行高偏好继续优先。Diff 用行内留白保持标题节奏与左右对齐，不让 CSS margin 折叠破坏比较布局。
- 有序与无序列表共用28px缩进；列表内段落无下间距，列表项之间和嵌套列表顶部均4px。标号使用辅助文字色与等宽数字，有序编号右对齐。
- 引用使用3px中性分隔线、左内边距16px和辅助文字色，无背景。提示块保留现有强调色边线与浅底，四种语气由后续需求处理。代码块取消单侧强调线，使用次级区域背景、1px完整分隔线、8px圆角、14×16px内边距、0.94em字号与1.65行高；行内代码使用细边框、4px圆角，不改变所在行高。
- 分隔线为1px主题分隔色，上下28px，不保留浏览器默认凹槽。表头采用次级区域背景，单元格选区叠加12%强调色；结构与操作不变。
- 链接默认不额外加粗，使用强调色文字、1px且40%强调色下划线、3px下划线偏移；悬停时下划线实色、背景6%，键盘焦点为2px描边。文字选区使用强调色22%与正文背景混合，平滑光标共用强调色，协作者个人光标颜色保持不变。
- 默认高亮统一使用 `--rb-highlight` / `--rb-highlight-ink`：亮色背景 `#FFF1B8`、文字继承正文；暗色背景 `#46380B`、文字 `#FFE9A0`。圆角2px，跨行分片连续绘制。设置预览通过自身 `color-scheme` 展示目标主题，不随当前应用主题串色。
- 空段落在编辑和只读状态下均常驻显示“¶ 空段落”，无需悬停或聚焦。提示仅为视图标记，不写节点属性、正文文本、历史或 Yjs；Diff 中原有空段落符号保留。
- 图片默认无可见边框，透明图片仍有画布背景；悬停为1px分隔色描边，NodeSelection 或预览按钮键盘焦点为2px强调色描边、外偏移2px。描边不占布局空间，题注与存储尺寸不变；窄屏以当前容器宽度约束显示，避免旧的交互宽度导致裁切。对齐按钮激活态使用正文强调色，缩放手柄触发条件不变。

## 各页面的内容重点

| 页面 | 首要内容 | 其他内容 |
| --- | --- | --- |
| 工作台 | 我的三列工作流（拖拽改状态），标题旁等你验证/停滞数字 | 右侧全项目动态；下方团队负载与完成节奏 |
| 文档 | 灰色页面中的单张大卡片，包含视图、计数、筛选、列表与分页 | 编号、标题、类型、状态、优先级、负责人、更新时间七列；标题可换行，分组共用列偏好及一个列设置入口 |
| 模板 | 灰底上的一张大卡片，顶部搜索/类型/来源筛选，内部43/57模板库与正文预览/编辑 | 模板库双列卡片，≤600px单列；工作区≤1100px切为目录/预览单区，保留输入/上传/版本冲突保护 |
| 成员 | 与文档列表一致的灰底大卡片，集中展示姓名与邮箱、项目角色 | 卡片内搜索、计数、刷新、分页及蓝色设置角色入口；不改变成员访问权限 |
| 编辑页 | 文档标题及正文 | 状态/负责人/优先级常驻，低频操作在更多菜单；辅助面板为目录/文档信息/AI 标注 |
| 账号 | 左侧资料/安全、右侧项目访问/AI | 教程默认折叠，凭证真实分页，密码和凭证表单/结果保持480×480并受视口约束 |

工作台采用岛屿布局：`--ui-navigation` 灰底上四块 12px 圆角的实色面板，间距 12px，不放日期问候和解释性小字。工作流列为中性浅底，列头显示状态圆点、名称和可跳转列表的数量；卡片 8px 圆角，标题突出，类型、编号、优先级、负责人和提醒收在顶部。仅本人负责时隐藏重复头像，窄卡先收起普通时间，再用人数替代头像，必要时提醒换行；停滞用红/橙胶囊、等你验证用青色胶囊。三个点菜单按钮常驻显示，触控保持 44px 命中区。拖动时可放下的列描虚线、悬停列染色。桌面首行根据窗口可用空间稳定定高，增减卡片只影响列内滚动，动态仅跟随；负载与完成节奏分排布固定高度，成员/完成详情内部滚动。窗口 ≤1100px 或工作区可用宽度 ≤1000px 时四块面板单列，每列显示5条并提供查看全部；≤760px 工作流改为 soft 样式 BingTabs 单列。日历、间隙和详情共享连续预览，移入详情不回退日期。状态始终配文字或无障碍名称。详见 [首页工作台](workbench-home.md#布局)。

工作台拖拽时突出「我的工作」与底部投放区，其余面板淡化；拖入「已完成」后向上和两侧扩大实际接收范围，四面板位置不变。窄屏仅增高目标，不改变其他落点的横向位置；取消或收尾后恢复。项目动态保留已有内容，首次读取、筛选和刷新使用半透明遮罩，等待 150ms 后显示，淡入淡出各 100ms；加载更多提前一个列表可视高度（至少 240px）开始预取，仅在底部显示延迟 150ms 的加载提示，列表保持可滚动、可打开条目。标签保持可操作，数据返回即更新，不等待动画或强制停留；新筛选回到顶部，同筛选刷新保留阅读位置，减少动效时关闭过渡与转圈动画。

完成节奏使用独立且不拦截事件的悬停指示框，以 160ms 移向当前格子，停留同样时间后更新详情；快速划过与间隙不切换内容。详情切换用 160ms 半透明淡入和 4px 向上归位，背景与尺寸保持稳定，连续切换取消旧动画，同日刷新不重播。点击、触屏轻点和键盘聚焦即时响应，减少动效时关闭指示框和详情动画，保留停留判断。

负载表使用同样的独立指示框，移动及状态颜色过渡为 160ms，行列强调跨间隙保持连续。滚动、尺寸变化和键盘聚焦时立即对齐格子，避开固定表头并跟随底部未指派行；框不拦截链接，触屏不保留模拟悬停，减少动效时直接切换。

文档列表使用一张实色 BingCard，12px 圆角、细边框，桌面外边距24px；顶部为带图标的 soft/lg 分段式 BingTabs，选中文字为蓝色，总数靠右。筛选、白色表头、列表和分页都位于同一张卡片内，按状态分组也复用这张外卡片。窄屏工具栏自然换行，表格横向滚动留在卡片内。

成员管理沿用文档列表的大卡片、外边距、表头和分隔线样式。卡片顶部左侧为项目成员标题，右侧为匹配人数与刷新；下方整行搜索姓名或邮箱，表格和分页也在卡片内。成员列表沿用现有全量读取，在前端分页，默认每页10条、可选10/20/50条，搜索回到第一页；设置角色使用蓝色文字入口。窄屏工具栏换行，表格在卡片内横向滚动。

模板管理同样使用实色 BingCard、12px 圆角与24px外边距。左侧浅灰模板库显示匹配数量和来源计数；每张模板卡片先显示正文缩略结构，再显示名称、用途、类型与章节数量，选中时用完整蓝色边框和勾选图标。右侧顶部为正文预览及复制/编辑操作，类型、来源、版本和只读状态位于模板名称上方，用途与正文以细线分隔，只读说明位于正文底部。桌面编辑表单将模板名称与所属类型按2:1放在同一行，用途说明独占下一行；模板库和正文编辑区按剩余视口高度内部滚动，高度预算包含卡片与页面底部留白，避免默认桌面出现外层溢出。窄屏字段纵向排列、筛选换行，目录/预览切换不销毁编辑器。

## 编辑器辅助面板

辅助面板默认目录，分段式 BingTabs 完整显示目录、文档信息和 AI 标注，关闭按钮独立。目录上方显示“本页目录”，条目使用 H1/H2/H3 图标和缩进区分层级；当前可见标题使用浅蓝底、蓝字和左侧轨道，保留长标题换行及多个可见标题的联动。宽度偏好默认360px、范围320–560px；窗口>960px且工作区≥920px才停靠，实际宽度不超过工作区−600px。BingSplitPane 在松手、键盘调整或重置时提交偏好；容器临时收窄不改 Cookie，恢复空间后恢复偏好。双击或 Enter 恢复360px，方向键微调，Home/End 到边界，Escape 取消拖动。设置与拖动共享同一偏好。

H1–H3 的章节链接入口使用20px `#` 文字按钮，默认辅助文字色、悬停/键盘焦点为强调色。按钮在正文之外，桌面位于版本标记外侧，优先避让 AI 编号；窄屏放在标题末尾，不能挤压标题或进入正文复制。章节链接与目录定位到达后，标题使用一次约900ms的无边框浅底强调，轻微亮起后淡出，不改标题文字、链接、高亮或 Diff 状态色；减少动态效果下静态呈现。正文版本标记继续沿用新增绿、修改琥珀黄、删除鲜红。

其余情况使用右侧抽屉。Tab、开合与宽度互相独立，跨断点收起抽屉，恢复桌面时沿用桌面开合。正文 viewport 缓存首个可见段落的 diffId 和相对偏移，宽度变化后只恢复内部阅读位置，不移动页面、不重建编辑器或改写选区。

抽屉复用 BingDialog 的 Escape、焦点圈定和关闭后焦点恢复；目录点击先定位正文，再关闭抽屉。右侧面板变化不能重建编辑器、共同编辑连接或图片上传任务。目录仅在可见 Tab 中提取和测量标题；关闭、切回属性或进入比较时停止扫描和动画。

AI 标注沿用项目主题：高亮使用 `--ui-accent`，浮动输入框复用 BingCard、BingTextarea 和 BingButton，正文编号使用 BingButton，侧栏编号使用 BingTag。输入框采用紧凑横排，取消与保存图标位于输入区右侧；快捷键通过按钮提示和可访问说明提供。控件保留组件库的圆角、焦点和亮暗主题，不占正文空间。单行编号优先位于选区末端上方，遇到其他文字时向附近空白避让；折行和跨段选区作为整体，输入框靠左放在选区顶部上方，编号放在左侧页边的顶部位置，避免遮住选中内容。列表原文、要求和编号都可以点击定位；多行定位到起始行，先平滑滚动正文，再短暂强调原文，编号以下方支点沿圆弧摆动并逐次减弱，不增加点击描边。减少动态效果时直接定位并静态强调。添加和编辑均保留当前正文宽度，窄屏标注操作先收起抽屉。

填写标注使用透明背景的 BingDialog 模态层。保存、取消或 Esc 前拦截页面滚轮、触摸滚动、外部点击和页面快捷键，并让输入框围绕中心轻晃、焦点回到输入区。Tab 只在输入、取消和可用的保存按钮间循环；文字编辑、输入法和长要求内部滚动照常工作。减少动态效果时显示静态输入提示和可访问消息；连续滚轮不会反复重启动画。取消、保存和卸载后移除拦截并清理动画。

标题随正文滚动，按 Enter 或失焦通过属性接口独立保存；失败保留输入并可重试或取消，其他在线页面收到通知后更新当前标题。标题上方显示文档类型和创建人，下方显示蓝色正式版本及版本保存状态，未保存为版本的正文修改用琥珀色文字提示。正式版本仅记录保存时的标题快照。桌面文档操作栏保持一行：返回文档、编号、正文/版本比较，随后是紧凑的状态、负责人和优先级；右侧依次为共同编辑头像、草稿同步图标、保存版本、更多操作和辅助面板开关。常用属性不单独占行，格式栏紧接其下。负责人用头像与姓名摘要展示，多选及独立保存行为不变。工作区实际宽度小于1120px时收为属性弹窗入口，小于760px时导航及属性入口在首行、右侧操作在第二行；取消不发请求，确认后一次 PATCH，失败保留选择。比较时当前属性只读。格式栏位于正文滚动区外，以“段落样式”和浅灰下拉框开头，菜单提供普通正文/H1/H2/H3；随后分组显示字形、列表与引用、链接/表格/图片/代码块、历史及 AI 标注。撤销、重做、高亮和组件块收进更多格式工具，快捷键与选区菜单仍可用。窄屏按组换行。另存为模板、属性历史、工作区提示和 AI 编辑状态收进文档更多菜单。

正文页边标记相对最新正式版本的变化：新增为 `--bing-success-strong`、修改为与版本比较一致的 `--bing-warning-strong` 琥珀黄色3px竖线。相邻同类标记跨段落间距绘制为一条完整笔画，仅整段两端保留圆角，遇到未修改块、不同变更类型或删除位置时断开；间距及热区由上下两块各占一半，点击仍只预览和恢复对应块。连续删除合并为 `--bing-red-500` 的8×3px圆角短横线，亮暗主题均使用饱和红色、100%不透明，位于块间缝隙中央，与竖线的中心轴对齐。桌面竖线贴正文左缘外14px，窄屏距正文视口左缘6px；新增/修改默认80%不透明，悬停、键盘聚焦、打开预览或定位修改时，当前块对应部分为5px、100%不透明；删除短横线相应加宽至10px。热区12px、触屏24px。浮层不占正文宽度，与 AI 标注编号分层避让，外侧保留标题章节按钮空间。

当前块同时出现与标记同色的浅底，强调层不带描边，向块边框盒外扩左右4px、上下3px，不改变正文布局。分隔线的强调范围按一行普通正文的高度居中展开，跟随用户字号和行高。正常动效在700ms内轻亮一次后保持淡色，移开后160ms淡出；减少动态效果时使用静态强调，不循环闪烁。该强调层不接管指针、不进入正文内容；删除标记不强调相邻正文。

悬停使用 BingTooltip 说明版本、状态及块数；点击打开最大480×360px的 BingCard，正文内部滚动，沿用版本比较渲染及个人阅读偏好。卡片包含旧版内容、恢复与比较入口；只读隐藏恢复，AI 锁或上传未处理时禁用并说明原因。支持正文右键菜单、ContextMenu、Shift+F10；Escape、外部点击和滚出视口关闭，焦点返回原正文选区。标题下“已修改 · N 处”可循环定位并静态强调，减少动态效果时直接滚动；卡片不使用入场动画。阅读与编辑设置提供默认开启、Cookie 持久化的“显示版本标记”。没有正式版本、模板页和比较视图不显示。

版本比较共用一行紧凑工具栏：旧版、箭头、目标、相邻版本开关与说明图标，随后为并排/统一、仅变化、前后变更及数量；空间不足时按组换行。版本号旁显示月日与时分，完整时间、保存人、编辑人与说明仍可从选项详情读取；当前草稿显示真实同步状态。去掉重复标题和只读属性说明行，辅助面板让出空间。加载失败时保留版本选择与重试入口。

并排正文使用等宽两栏，中间40px变更操作区；灰底列标题在内部滚动时固定，并随正文横向滚动对齐。正文沿用编辑页的默认字号和个人偏好，普通段落间不画横向表格线。当前变更用左侧3px蓝线和浅蓝中间标记定位，回退按钮位于中间；右侧为紧凑小地图。可用内容宽度<860px默认统一，用户显式选择优先；窄屏手动并排时只在差异内容内横向滚动。正文与比较通过 `v-show` 保留编辑器实例；版本按需加载、相邻联动、完整连续 Diff、小地图与草稿回退沿用现有规则。

## 显示设置

设置弹窗固定900×600，头部、外观与交互/阅读与编辑分类和 footer 保持原位，中部独立滚动；尺寸受视口限制。分类切换不卸载输入，恢复默认只影响当前分类。应用主题与亮/暗正文配色的编辑目标独立。字号、透明度、行高和宽度允许半成品输入，Enter/失焦校验；正文宽度与面板宽度同时提供数字和 BingSlider。右侧预览包含标题、正文、强调、链接和布局比例，窄屏移至下方。Cookie 写入失败或静默拒绝时保留当前效果、明确提示尚未保存并允许重试。

设置分类带图标，选中项为蓝字浅蓝底。外观页左侧说明、右侧三张主题缩略卡，名称和单选圆点置于卡片下方；指针开关与样式示意同行。阅读页用下拉框选择编辑的亮/暗配色；行高与数值框同行，宽度数值放在滑杆上方，滑杆右侧为图标重置。预览使用原型中的工作台正文、链接与高亮示例，下方以微缩页面展示正文和辅助面板比例。

阅读页在字号之前提供独立的正文字体、代码字体及实际字体示例，默认均为 Maple Mono NF CN。预设打开设置时按混合中英文的实际字宽检测，未安装项禁用并显示“本机未安装”；不以 `document.fonts.check` 判断命中。安全上下文支持 [`queryLocalFonts()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/queryLocalFonts) 时显示“读取本机字体”，仅在点击后请求权限，按系列去重并放入可搜索、自动虚拟化的 BingSelect；不支持或拒绝时保留预设与手动输入。手动输入未命中时明确提示回退，用户确认后才应用。右侧预览包含行内代码，正文与代码各用自己的字体，既定颜色不变。

正文字体覆盖标题、正文节点、图片题注、只读内容、版本 Diff 和选区历史；代码字体覆盖行内/块级代码及其 Diff。Header、导航、工具栏、属性、设置控件、AI 标注浮层和 Toast 保持界面字体。切换字体保持当前阅读段落，并更新目录、标注、版本标记和平滑光标的几何位置。

读取到的本机字体名称缓存在当前浏览器的 localStorage，重新打开设置或刷新页面直接恢复列表，不自动请求字体读取权限。有缓存时入口显示“重新读取本机字体”，用于安装或卸载字体后更新列表；重新读取失败仍保留旧列表。恢复阅读默认只重置字体选择，不清空字体列表。存储失败时提示缓存未保存，当前页面内仍可继续使用。

属性变更记录下方展示紧凑的关联文档列表，显示标题、编号和文字状态，默认显示三篇，其余可展开。标题通过原生新标签页链接打开，更多菜单可解除关联，解除后可撤销；双方文档都能看到关系。关系加载失败显示重试入口，不冒充空列表。

添加弹窗使用服务端分页查询，按标题或编号搜索，每页八项。弹窗采用固定高度，随小屏视口收缩；搜索结果和已选区域各自固定高度并独立滚动，空结果、勾选及错误提示不改变弹窗尺寸。当前文档由查询条件排除，已关联项勾选且不可重复添加。中文组词结束后再更新搜索；切换查询或分页回到结果顶部并保留已选项，确认成功后关闭，失败保留选择和错误提示。取消不写入。单次最多选择 100 篇。弹窗和窄屏属性抽屉沿用 BingDialog 的嵌套焦点与 Escape 行为。

## 组件与验收

优先使用已安装的 `@moubing/bing-ui`，具体 API 以 [组件接入说明](bing-ui.md) 为准。路由用 NuxtLink，同页视图用 BingTabs，临时对话用 BingDialog。业务样式可统一间距和色彩，不在业务层修补组件库内部行为。

改动后检查亮暗主题、320/390/960/1440px、Tab 键及方向键、焦点恢复、真实空状态和错误状态。浏览器验证使用无头模式。布局验收可使用固定数据，但保存、权限和共同编辑的持久化正确性需依照 [开发验证矩阵](development.md#按改动选择验证) 选择对应测试。
